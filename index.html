AgroTok Publisher

Короткие видео о сельском хозяйстве России

Сервис собирает открытые новости агропромышленного комплекса из публичных Telegram-каналов, готовит короткий вертикальный ролик с озвучкой и субтитрами и — по решению автора — публикует его в TikTok через официальный Content Posting API.

Что делает сервис

  • читает публичные Telegram-каналы о сельском хозяйстве;
  • формирует сценарий ролика по фактам источника, без домыслов;
  • озвучивает текст и собирает видео 1080×1920 с субтитрами;
  • публикует результат в аккаунт TikTok только с согласия владельца аккаунта.

Что сервис НЕ делает

  • не читает личные переписки;
  • не получает пароль от TikTok;
  • не публикует ничего без явной команды пользователя.

Доступ к аккаунту

Авторизация проходит через OAuth TikTok. Сервис получает только разрешённые пользователем права (user.info.basic, video.upload, video.publish) и может быть отключён в настройках TikTok в любой момент.
