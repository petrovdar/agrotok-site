2. Какие данные обрабатываются

ДанныеЗачемОткуда

3. Чего Сервис не делает

  • не получает и не хранит пароль от TikTok;
  • не читает личные сообщения и закрытые каналы;
  • не передаёт токены третьим лицам и не продаёт данные;
  • не публикует контент без явной команды пользователя.

4. Хранение и защита

Токены хранятся в защищённом хранилище на устройстве/сервере оператора, доступ ограничен. Токены удаляются при отзыве доступа в TikTok либо по запросу пользователя. Срок хранения служебных логов — не более 90 дней.

5. Передача данных

Данные передаются только в TikTok (для публикации контента) и в сервисы синтеза речи/модели текста, необходимы для создания ролика. Перечень обработчиков: TikTok (публикация), Yandex Cloud SpeechKit (озвучка), DeepSeek (генерация сценария). Передача осуществляется в объёме, необходимом для работы функции.

6. Права пользователя

  • отозвать доступ в любой момент: TikTok → Settings → Security → Manage app permissions;
  • запросить удаление сохранённых данных по адресу выше;
  • получить информацию об обрабатываемых данных.

7. Дети

Сервис не предназначен для лиц младше 13 лет (или иного возраста, установленного законодательством страны пользователя).
